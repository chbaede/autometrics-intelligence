# AutoMetrics Intelligence

> **Global Automotive OEM Performance & Investor Intelligence**

AutoMetrics Intelligence is a source-backed quantitative web platform for tracking, benchmarking, and analyzing global automotive manufacturers (Volkswagen Group, Toyota, Tesla, BYD, BMW Group, Mercedes-Benz, Stellantis, Hyundai Motor, Ford, General Motors) based strictly on official investor relations releases, quarterly financial reports, annual filings, and earnings conference presentations.

---

## ⚡ Key Highlights & Core Features

* **Zero Fabricated Data**: 100% of data points link directly to official primary IR documents with date, doc type, title, and page number citations.
* **Why This Number? Modal**: Immediate provenance audit on any metric showing raw reported values, functional currency, formula, and comparability nuances.
* **Strict Comparability Protection**: Automatic alerts and warnings when comparing differing perimeters (e.g. *Retail Deliveries vs. Wholesale Shipments*, *Automotive FCF vs. Group FCF*).
* **Multi-OEM Comparison Engine**: Dynamic side-by-side benchmarking for 2 to 8 automakers with multi-metric matrix tables and CSV/JSON export.
* **Regional Analysis**: Unaltered regional delivery breakdowns for China, Europe, North America, India, South Korea, etc.
* **Guidance & Outlook Tracker**: Forward-looking management target corridors (%) with midpoint markers, assumptions, and risk factors.
* **Source Explorer**: Searchable and filterable archive of primary OEM filings and investor decks.
* **Data Coverage Matrix**: Public audit matrix disclosing availability status across reporting quarters.

---

## 🛠️ Tech Stack & Architecture

* **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
* **Routing**: React Router DOM v6
* **Data Model**: Normalized, strictly-typed static TS modules
* **Validation**: Automated schema checks and calculation unit tests via TSX
* **Deployment**: Static SPA deployable to GitHub Pages or any static host

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Run Data Validation & Unit Tests
```bash
npm test
npm run validate-data
npm run typecheck
```

### 4. Build for Production
```bash
npm run build
```
